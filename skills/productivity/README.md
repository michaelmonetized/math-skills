# Productivity

General workflow tools, not specific to one manuscript.

## User-invoked

Reachable only when you type them (Claude Code: `disable-model-invocation: true`; Codex: `policy.allow_implicit_invocation: false` in `agents/openai.yaml`).

- **[grill-lemma](./grill-lemma/SKILL.md)**: The same relentless interview, saving nothing. Out of the dilemma, into the lemma.
- **[hand-wave-off](./hand-wave-off/SKILL.md)**: Hand off to another agent or coauthor, every claim labelled proved, formalised, checked, heuristic, conjectured, or refuted.
- **[teich-me](./teich-me/SKILL.md)**: Learn a new area over several sessions, with a stateful workspace, verified resources, exercises, and spaced recall.
- **[to-quaternionnaire](./to-quaternionnaire/SKILL.md)**: Write the questions for the one expert who knows (or a MathOverflow draft), after doing the literature homework.
- **[wait-how-much](./wait-how-much/SKILL.md)**: That didn't land: re-pitch it in plain words with one concrete instance, sizes, constants, and a feasibility estimate.

## Model-invoked

Model- or user-reachable (descriptions carry trigger phrasing so the model can reach for them).

- **[epsilon-delta-grilling](./epsilon-delta-grilling/SKILL.md)**: The interview primitive: statement, conventions, each hypothesis, edge cases, novelty, what counts as done.
- **[writing-for-a-gentzen](./writing-for-a-gentzen/SKILL.md)**: Writing `AGENTS.md`, skills, and agent-facing docs for a maths project.
