# Misc

Tools kept around but rarely used, not promoted in the plugin.

- **[git-guardrails-cauchy-code](./git-guardrails-cauchy-code/SKILL.md)**: Claude Code hook that blocks history-rewriting git commands in a shared paper repo.
- **[migrate-to-shoe-horner](./migrate-to-shoe-horner/SKILL.md)**: Modernise old LaTeX (`$$`, `eqnarray`, `\bf`, `\over`) one idiom at a time without touching the mathematics.
- **[sheaffold-exercises](./sheaffold-exercises/SKILL.md)**: Scaffold problem sheets with hints and solutions that compile with or without answers.
- **[setup-pre-commutative](./setup-pre-commutative/SKILL.md)**: Pre-commit hooks that compile the paper, catch undefined refs and citations, build Lean, and run numerical checks.
