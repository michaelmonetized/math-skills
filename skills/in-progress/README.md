# In Progress

Beta. Public on purpose: try them and say what breaks. Excluded from the plugin and the top-level reference list, and they can change or disappear without warning.

The plugin won't give you these. Install one directly:

```bash
npx skills@latest add michaelmonetized/math-skills --skill=<name>
```

- **[chief-of-stalks](./chief-of-stalks/SKILL.md)**: Run a long research goal through sub-agents, thinking locally (the task) and globally (the environment).
- **[claude-hand-wave-off](./claude-hand-wave-off/SKILL.md)**: `hand-wave-off`, then launch a background Claude Code session seeded with the note.
- **[loop-space](./loop-space/SKILL.md)**: Grill out specs for the recurring loops of research life: arXiv monitoring, refereeing, seminars.
- **[setup-lean-deep-moduli](./setup-lean-deep-moduli/SKILL.md)**: Lean 4 + Mathlib project with enforced module boundaries and a sorry-free gate on the main theorems.
- **[writing-bettis](./writing-bettis/SKILL.md)**: Build a talk or exposition one beat at a time, grounding each concept before it is used.
- **[writing-fractals](./writing-fractals/SKILL.md)**: Mine raw fragments of exposition: the one-line reason, the motivating example, the leading word.
- **[writing-shape-theory](./writing-shape-theory/SKILL.md)**: Shape raw material into exposition, block by block, arguing each structural choice.
